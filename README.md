# Server-side Programming with Node.js

Lecture-wise notes, tested practical code and assignments for learning server-side programming with Node.js.

**Taught by:** Yousuf Naveed Khan, Senior Faculty
**Hosted by:** Aptech Gulshan 2, Karachi

## Repository Structure

Each lecture has its own folder named `LectureNN-Topic`, containing the practical (runnable) code files from that class and a `README.md` with notes, expected output, common questions and the assignment.

```
Lecture01-Introduction/
  README.md
  01-hello.js
  02-global-objects.js
  ...
```

Lecture notes are written in Roman Urdu with light English; code and technical terms are in English.

## Prerequisites

- A computer with internet access
- Basic JavaScript knowledge is helpful but not required

## Tools

- [Node.js](https://nodejs.org) (LTS version) and npm
- [VS Code](https://code.visualstudio.com)
- Git & GitHub

## How to Run a Lecture's Code

```bash
cd Lecture01-Introduction
node 01-hello.js
```

Code in this repository is tested on Node.js v22.21.0.
