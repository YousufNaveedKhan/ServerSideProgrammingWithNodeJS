# Server-side Programming with Node.js

A lecture-by-lecture course on building server-side applications with Node.js — from the basics of client-server architecture to REST APIs, MongoDB, AI integration and deployment.

**Taught by:** Yousuf Naveed Khan, Senior Faculty
**Hosted by:** Aptech Gulshan 2, Karachi

## What This Course Covers

- Client-server architecture and how web servers work
- Node.js fundamentals: features, architecture, installation, npm
- Built-in modules (`http`, `url`, `events`, `querystring`) and local modules
- Sending emails and uploading files
- Express.js and RESTful APIs
- Asynchronous programming: callbacks, Promises, async/await, event loop
- MongoDB integration and CRUD APIs
- Integrating AI capabilities into Node.js applications
- Building a full web application, uploading it to GitHub and deploying it

## Repository Structure

Each lecture has its own folder named `LectureNN-Topic`, containing the practical (runnable) code files from that class and a `README.md` with notes, expected output, common questions and the assignment.

```
Lecture01-Introduction/
  README.md
  01-hello.js
  02-global-objects.js
  ...
```

Lecture notes are written in Roman Urdu with light English; code and technical terms are in English.
